CELL ARENA — TAM SÜRÜM
========================
Özellikler:
- Oyuncu giriş sistemi
- İnternet üzerinden HTTP tabanlı multiplayer durum senkronizasyonu
- Hareket ve skor/leaderboard
- Admin paneli
- Kick / ban / tüm oyuncuları çıkar
- Skin yükleme
- Responsive temel arayüz

KURULUM:
1. Bilgisayara Node.js kur.
2. Bu klasörde terminal aç.
3. npm install
4. npm start
5. Tarayıcıdan http://localhost:3000 aç.

ADMIN:
http://localhost:3000/admin.html
Kullanıcı: admin
Şifre: admin123

İNTERNETE AÇMA:
Sunucuyu bir VPS/cloud sunucusunda çalıştırıp 3000 portunu açabilir ve alan adını bu sunucuya yönlendirebilirsin.
